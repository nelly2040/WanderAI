# WanderAI – AI Travel Planner

A mobile-first PWA travel planning app powered by Groq AI (Llama 3.3).

## Deploy to GitHub Pages
1. Create a new GitHub repo (e.g. `wanderai`)
2. Upload all files from this folder
3. Settings → Pages → Deploy from main branch
4. Live at: https://YOUR-USERNAME.github.io/wanderai/

## Features
- 30+ destinations with real 2026 prices
- AI trip planner (Groq Llama 3.3 — built-in key)
- Trip & itinerary management
- Real-time travel companion with weather/safety/language
- Budget & expense tracker with AI insights
- Sign up / sign in with local auth
- Dark mode, PWA installable, offline support
